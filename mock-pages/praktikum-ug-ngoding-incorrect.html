Pada lab ini Anda membuat Lexer (scanner) untuk bahasa pemrograman sederhana bahasaKu. Lexer mengubah source code menjadi urutan token.

File yang diperlukan. Download ketiga file berikut ke dalam satu folder:

  1. bahasaku.py : program utama
  2. bhs_lexer.py : file yang Anda lengkapi (berisi TODO 1-9)
  3. uji_lexer.bhs : contoh program bahasaKu untuk pengujian

Download Panduan berikut dan ikuti langkah-langkah pada Panduan Lab Analisis Leksikal.

Kerjakan terlebih dahulu pada komputer Anda dan pastikan program yang Anda buat sudah berjalan sesuai dengan yang diminta. Jika sudah, salin isi program bhs_lexer.py yang telah Anda buat ke answer box di bawah untuk mendapatkan nilai pada lab ini.

Step by step pengerjaan soal:

  • Kerjakan soal dengan menggunakan IDLE (Python 3.10) pada komputer.
  • Download ketiga file di atas dan simpan dalam satu folder.
  • Lengkapi bagian TODO pada file bhs_lexer.py. Jangan ubah file bahasaku.py, dan jangan mengubah nama class dan method yang sudah tersedia.
  • Jangan menggunakan re (regular expression) maupun eval(), dan jangan melakukan hardcode terhadap input atau output tertentu.
  • Jalankan bahasaku.py dengan argumen uji_lexer.bhs, lalu pastikan output sama dengan contoh pada panduan.
  • Jika sudah benar, salin seluruh isi bhs_lexer.py ke answer box, lalu klik Check. Nilai akan muncul setelah Check selesai diproses.
  • Program diuji dengan beberapa test case, termasuk hidden test case.
  • Apabila jawaban masih belum benar, perbaiki di komputer, salin ulang, lalu Check kembali. Pengerjaan dapat diulang hingga mendapatkan hasil yang benar.
